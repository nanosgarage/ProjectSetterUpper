*Project SetterUpper* aims to speed up the tedious task of creating project directories when setting up a new project.
This might be tailored specifically to my workflow, but for the most part I find it annoying having to sift through Blender's sluggish file manager to routinely set up new projects when working with the program.

**What this does**
- Creates a project directory in specified folder
- Sets your primary scene's output to a new "output" folder (name can be changed) immediately.
- Creates a textures folder within the directory
- Allows you to specify scene's camera resolution and framerate within the same window.

This was designed to combat the tedious task of sifting through multiple menus which has to be done every time I start a new Blender project.

**How to use**
- Install the add-on by dragging the zip located in this repo into blender.
- Go to File -> Setup Project, and you're presented with the menu.
